# healthleticx Website

Website von healthleticx (React + Vite + TypeScript), gehostet bei Cloud86 unter der eigenen Domain.

- Entwickeln: `npm install` und `npm run dev`
- Bauen: `npm run build` (Ergebnis in `dist/`, diesen Ordner zu Cloud86 hochladen)
- Prüfen: `npm run lint`

Unterseiten sind direkt verlinkbar: `#anfrage`, `#impressum`, `#datenschutz`, `#gesundheit`.

Schreibweise immer **healthleticx** (mit x). Die Website spricht in der Ich-Form oder neutral, nie in der Wir-Form.

Rechtliche Leitplanken: siehe `CLAUDE.md`, Prüfbericht: `WEBSITE_CHECKLISTE.md`.
